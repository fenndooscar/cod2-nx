# Addresses that must never be declared as functions, even if they look like gaps.
# tools/huecos.py skips them. One per line, `0x` followed by eight hex digits; the rest of the line is a
# comment.
#
# This file is for cases the codegen's own log does not explain. It holds one entry, the import thunk
# below. Everything else is reported in app/codegen.log and tools/huecos.py drops it there.
#
# The two causes, and the log line that identifies each:
#
#   "Analyze: function 0xXXXXXXXX not in any code region"
#     A data block embedded in .text. It is a gap in the function layout, so it looks exactly like an
#     unclaimed function, and it is not one. Declaring it registers an address that gets no body.
#
#   "[functions] 0xXXXXXXXX outranked by import"
#     An import thunk. The declaration takes precedence over the import the codegen would otherwise
#     resolve, so the call stops being __imp__KeTlsSetValue and becomes sub_XXXXXXXX - which has no body.
#
# 0x82494C54 is that import thunk, in the import block at the end of .text. It has to be written here by
# hand because the warning above is only printed while the address is NOT declared: the declaration wins
# the authority check, so the log goes quiet exactly when the entry is needed.
0x82494C54
#
# Neither cause is a codegen error. Both leave the address in the function table and surface much later, at
# link time, as
#
#     lld-link: error: undefined symbol: sub_XXXXXXXX
#     >>> referenced by .../cod2_init.cpp.obj:(struct PPCFuncMapping *PPCFuncMappings)
#
# with nothing pointing at huecos.toml. tools/comprobar_huecos.py is the check that catches it before the
# build does.
#
# The previous game's 49 addresses were removed with the rename: they belong to Need for Speed: Most
# Wanted's .text and mean nothing here.
